# 한전형 AI 플랫폼 구축 사업

## 개요

SKT A.X 플랫폼을 기반으로 하고, 미지원 영역은 별도 개발로 채우는 구조를 검토 중.
Text to SQL(다답) 건은 제주 본부 대상 솔루션 납품 형태로 별건 진행 (상주 불필요).

## 완료된 것

- [x] 사업 현황 정리 (08/06) — 9~10월 발주 예정, 대상 제주, Text to SQL, 솔루션 납품
- [x] A.X 플랫폼 설명 청취 및 기능 커버리지 1차 확인

## 메모

- A.X는 SKT 상품이라 고정 금액 발생. 설치는 아키텍처 팀 지원, 프로퍼티 추가 등 공통 수정은 추가 비용 없음.
- A.Biz 소스는 일부만 확보되며 소유주는 SK (챗 빌더 포함) → 사용 포털은 별도 개발.
- RAG는 현재 Azure 사용 중.
- 관측·통계는 SKT 위주로 개발되어 있어 한전용 별도 개발 필요 전망.
