# ADR-016: 대시보드 위젯 크기 모델 — 고정 프리셋 + 반응형 컬럼 + 비례 높이

## 맥락

대시보드 위젯의 크기/배치를 어떻게 다룰지 결정해야 했다. react-grid-layout(v2)의 기본은 자유 드래그 리사이즈지만, 차트 위젯은 임의 크기보다 정형 크기가 가독성·정렬에 유리하다. 동시에 상세 패널 폭이 넓게 변하므로(채팅 사이드바와 split-panel) 화면 폭에 따른 적응이 필요했다. 또한 위젯 높이가 고정이면 폭이 넓어질 때 차트가 넓적한 띠처럼 보이는 문제가 있었다.

## 선택지

### 옵션 A: 자유 리사이즈 (그리드 12칸, 드래그 핸들 크기 조정)
- **장점:** 유연함, RGL 기본 기능
- **단점:** 크기가 제각각이라 정렬 안 됨, 차트 가독성 들쭉날쭉, 저장 좌표 복잡
- **비용/노력:** 낮음(기본)

### 옵션 B: 고정 프리셋 2종 + 반응형 컬럼 + 비례 높이
- **장점:** 일관된 정형 배치, 화면 폭 적응, 자연스러운 높이 비율, 단순한 UX(버튼 2개)
- **단점:** 계산 로직(컬럼/행높이/크롬) 직접 관리, "최대(콘텐츠 높이)" 프리셋과 비례 높이의 상호작용 주의
- **비용/노력:** 중간

## 결정

**옵션 B를 선택한다.** 구체 모델:

- **프리셋 2종:** `최소`(1칸×4행), `최대`(2칸×auto — 콘텐츠 높이를 4행 배수로 스냅). 자유 리사이즈는 끔.
- **너비 단위 = 1칸** → 그리드 컬럼 수 = 한 줄 위젯 수. 반응형 `colsForWidth`: ≥1200→4, ≥700→2, else 1열.
- **편집 모드는 4열 고정**(MAX_COLS) — 저장 좌표를 캐노니컬로 유지(아래 트레이드오프 참조). 조회만 폭 따라 reflow.
- **비례 높이:** `rowHeight = clamp(colWidth × 0.18, 40, 130)`. 폭이 넓어지면 위젯도 같이 커짐.
- **캐노니컬/표시 레이아웃 분리:** 저장본은 프리셋 w/h + 4열 좌표, 렌더본은 `fitToCols`로 현재 컬럼에 맞춤. `onLayoutChange`는 x/y만 반영.
- **드래그 격자 스냅:** RGL v2 `constraints=[snapToGrid(W_UNIT,H_UNIT), gridBounds]`.
- 관련 상수/계산은 `lib/chart-height.ts`에 일원화.

## 근거

차트 대시보드는 "임의 크기"보다 "정형 슬롯"이 시각적으로 깔끔하고, 사용자는 크기를 미세 조정하기보다 작게/크게만 원한다 → 프리셋 2개로 충분. 너비 단위를 1칸으로 두면 컬럼 수가 곧 한 줄 위젯 수가 되어 반응형이 직관적이다. 고정 높이는 폭 변화 시 비율이 깨지므로 컬럼 너비에 비례시켜 자연스럽게 했다. 편집을 4열로 고정하면 좁은 화면에서 저장해도 넓은 화면 배치가 보존된다.

## 결과

- **트레이드오프 1:** `최대` 프리셋 높이는 콘텐츠 px 기반이라, 비례 rowHeight가 큰 상태(2열)에서 적용하면 빈 공간이 생길 수 있음.
- **트레이드오프 2:** 편집을 4열 고정하므로 좁은 패널에서는 가로 스크롤 발생(편집은 보통 넓은 화면에서 수행).
- **재검토 시점:** 위젯 종류가 늘거나 사용자가 중간 크기를 요구하면 프리셋 추가 검토.
- **영향 컴포넌트:** `lib/chart-height.ts`, `components/dashboard-detail.tsx`, `components/dashboard-widget.tsx`, `components/echarts-chart-block.tsx`(콘텐츠 높이 추출).
