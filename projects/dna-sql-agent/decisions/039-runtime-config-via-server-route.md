# ADR-039: 배포처마다 달라지는 화면 설정은 빌드가 아니라 서버 라우트에서 읽는다

## 맥락

폐쇄망 고객사는 지도 배경 타일을 사내 서버에서 받아야 한다. 외부 타일 서버에 닿지 못해 배경이 비어 보이기 때문이다.

기존에도 `NEXT_PUBLIC_MAP_TILE_URL` 이 있었으나 두 가지가 걸렸다.

- `NEXT_PUBLIC_` 값은 `npm run build` 시점에 코드에 박힌다. 이미지 빌드 중 빌드가 돌므로, 값을 바꾸려면 고객사마다 이미지를 다시 만들어야 한다.
- 지도 테마 토글을 켜면 그 값을 무시하고 프리셋(외부 서버)으로 넘어갔다. 설정해도 버튼 한 번에 외부로 나갔다.

화면 설정이면서 배포처마다 달라지는 값을 어디서 읽을지 정해야 했다.

## 선택지

### 옵션 A: 빌드 타임 env 유지, 적용 범위만 넓히기
- **장점:** 변경량이 가장 적다. 런타임 조회가 없어 화면이 즉시 그려진다.
- **단점:** 고객사마다 이미지 재빌드가 필요하다. 하나의 배포 산출물로 여러 고객사를 덮는 지금 방식과 어긋난다.
- **비용/노력:** 낮음

### 옵션 B: 서버 라우트가 요청 시점에 env 를 읽어 내려주기
- **장점:** 이미지는 한 벌로 두고 `.env` 만 바꿔 재기동하면 된다. 컨테이너 env 가 파일보다 우선하므로 배포 도구와도 맞는다.
- **단점:** 화면이 뜬 뒤 설정을 한 번 받아오므로, 받아오기 전에는 기본값으로 그린다. 라우트가 하나 늘어난다.
- **비용/노력:** 중간

### 옵션 C: 백엔드 설정 섹션으로 편입 (`config/*.json` + 관리자 화면)
- **장점:** `chart.engine` 등과 같은 체계로 일관된다. 관리자가 화면에서 바꿀 수 있다.
- **단점:** 백엔드 스키마·설정 API·관리자 UI 까지 건드려야 한다. 지도 타일은 설치 시 한 번 정하고 거의 바꾸지 않는 값이라 과하다.
- **비용/노력:** 높음

## 결정

**옵션 B를 선택한다.**

`/map-config` 가 요청마다 `process.env` 를 읽어 모드별 타일 표를 JSON 으로 내려주고, 지도 컴포넌트가 그 값으로 그린다. 설정이 하나도 없으면 지금까지처럼 공개 지도 서버 프리셋을 쓴다.

## 근거

배포 산출물은 고객사와 무관하게 한 벌이어야 한다는 것이 이 제품의 전제다. 옵션 A는 그 전제를 깬다.

옵션 C가 체계상 더 맞지만, 지도 타일은 설치 담당자가 `.env` 를 채우는 시점에 한 번 정하고 이후 바뀌지 않는 값이다. 같은 성격의 값(DB 주소, 포트, 모델 경로)이 이미 `.env` 에 있으므로 그쪽에 붙이는 편이 설치 절차와 일치한다. 관리자가 운영 중 바꿔야 할 필요가 생기면 그때 옵션 C로 옮긴다.

받아오기 전 기본값으로 그리는 단점은, 폐쇄망에서 프리셋이 어차피 실패해 배경만 잠깐 비는 정도라 수용했다.

## 결과

- 설정 없이 기동하면 종전과 동일하게 동작한다. 기존 배포에 영향이 없다.
- `NEXT_PUBLIC_MAP_TILE_URL` 계열도 계속 읽어 하위 호환을 유지한다. 다만 새 설치에는 쓰지 않는다.
- 변수는 화면 용어를 그대로 따른다. `MAP_TILE_URL`(기본 모드), `MAP_TILE_URL_SIMPLE`·`MAP_TILE_URL_SIMPLE_DARK`(심플 모드).
- **지정한 모드만 화면 토글에 남긴다.** 없는 값을 다른 값으로 메우지 않는다. 타일이 한 종류뿐인 폐쇄망에서 눌러도 아무 변화가 없는 버튼이 생기지 않는다. 단 심플 모드의 밝은·어두운은 짝이라, 한쪽만 주면 나머지를 채워 다크 모드에서 지도가 사라지지 않게 한다.
- 기본 모드에는 다크 변형을 두지 않는다. OSM 표준 타일이 스타일 한 벌만 제공하기 때문이다. 사내 서버가 상세 스타일의 다크를 갖고 있어도 지금은 지정할 수 없으며, 필요해지면 변수를 넷으로 늘린다.
- 출처 표기를 비우면 OpenStreetMap 표기가 붙는다. 사내 타일이 대개 OSM 자료 기반이라 표기를 지우면 라이선스 문제가 된다.
- 같은 방식이 필요한 다른 화면 설정(예: Plotly 를 CDN 대신 어디서 받을지)이 생기면 이 라우트에 얹을 수 있다.
