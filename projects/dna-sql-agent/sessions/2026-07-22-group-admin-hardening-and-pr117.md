# 2026-07-22 — 그룹 관리자 기능 마무리, PR #117 머지

## 목표

7/16~7/21에 걸쳐 구현한 그룹 관리자(Group Admin) 기능을 실사용 가능한 수준으로
마무리 — 커넥션 위임 시 기본 권한 자동 시딩, 사용자별 권한 매트릭스의 스코프
누락 버그, 다수의 정렬/표시 버그를 해소하고 PR을 생성·머지했다.

## 수행한 작업

1. **`default_grant` 자동 시딩** — 커넥션이 그룹에 위임되는 시점에
   `systems.default_accessible=true`인 시스템을 그 그룹의
   `group_system_default_grants`에도 자동으로 켜진 채 시작하도록 함(최초 1회,
   기존 값 있으면 유지) → `896f6c7`
2. **기본/admin 그룹 예외 확정** — 이 두 그룹은 그룹 관리자가 없어 위임 개념이
   적용되지 않으므로, 신규 가입·그룹 이동 시 `default_grant` 대신 시스템 전역
   `default_accessible` 기준으로 권한을 초기화하도록 재확인·보강 → `b2a4faa`
3. **사용자별 권한 매트릭스 스코프 제한** — 시스템 관리자 화면에서 그룹 선택을
   필수화하고 컬럼을 그룹 파생 스코프로 제한(그룹이 위임받지 않은 시스템에
   권한을 잘못 줄 수 있던 문제 해결). admin/기본 그룹은 예외적으로 전체 시스템
   노출 → `4f22e13`
4. **벌크 그룹 이동** — 그룹원 관리 다이얼로그의 대량 편입/추방을
   `POST /admin/users/bulk-move` 단일 트랜잭션으로 처리(부분 실패 시 전체
   롤백). 기존 N번 개별 PUT 방식에서 전환 → `48ec272`
5. **그룹 편입 후보 목록 페이징 전환**, **연결/시스템 목록 이름 검색+정렬** 추가
   → `47eba1c`, `78c27f7`
6. **버그 수정 다수**:
   - `/me` 응답이 JWT 클레임의 스탈 그룹명을 반환하던 문제 → DB 조회로 변경
     (`3c32b45`)
   - 멤버 관리 다이얼로그 `is_admin`이 다른 그룹 관리자에게도 잘못 표시되던
     문제 — 스코프 조건 오류 (`896f718`)
   - Korean/English 혼용 정렬이 깨지던 문제 전반 — 연결/시스템/그룹/사용자
     권한 목록 등 다수 지점에 `COLLATE "und-x-icu"` 적용 (`b103070`, `f9058f2`)
     → [[knowledge/troubleshooting/postgres-collate-korean-english-mixed-sort]]
   - 커넥션 위임 해제 시 그룹 배타 소유 시스템 → `inactive` 전환 + 사용자 권한
     회수 캐스케이드 (`39321c7`)
   - 시스템 목록에 그룹 배타 소유 여부(`created_by_group_name`) 노출 (`84e3d05`)
   - 그룹 수정 다이얼로그 DB 연결 권한 목록 정렬을 표시명 기준으로 수정
     (`4fc4590`)
7. **매뉴얼 정비** — `GET /api/v1/manual` 응답에 `group_admin` 필드 추가,
   그룹 관리자 전용 매뉴얼 신설 (`6336fae`, `228e3f7`)
8. **테스트 보강** — `tests/test_group_admin.py` 벌크 이동·위임 해제
   캐스케이드·`default_grant` 시딩 9건 신규, 총 19건 전부 통과 (`94ee39d`)
9. PR #117 생성·머지 (백엔드), `docs/group-admin-design.md` v0.9 갱신

## 핵심 결정

- **결정 1:** 사용자별 권한 매트릭스의 컬럼을 "전체 시스템"에서 "선택한 그룹의
  파생 스코프"로 제한(admin/기본 그룹 예외) — 그룹이 위임받지 않은 시스템에
  권한을 부여할 수 있던 설계 허점을 막음
  → ADR: [[decisions/026-group-admin-v0.9-refinements]]
- **결정 2:** 벌크 그룹 이동을 N번의 개별 PUT 대신 단일 트랜잭션 API로 전환 —
  부분 실패 시 일부만 이동되는 정합성 문제 방지
  → ADR: [[decisions/026-group-admin-v0.9-refinements]]

## 배운 것

- PostgreSQL 기본 정렬(`C`/`ko_KR` 등)은 한글/영문이 섞인 텍스트를 코드포인트
  기준으로 정렬해 사용자 기대(가나다 → ABC 또는 그 반대의 일관된 순서)와
  어긋난다 — 여러 목록(연결/시스템/그룹/권한)에서 같은 증상이 반복해서
  나타났는데, 근본 원인은 하나였다. `COLLATE "und-x-icu"`를 정렬 컬럼에 붙이면
  ICU 기반의 언어 중립적 정렬로 해결됨
  → [[knowledge/troubleshooting/postgres-collate-korean-english-mixed-sort]]
- 새 역할(그룹 관리자)을 도입한 뒤에도, 코드베이스 곳곳에 `is_admin`/`isAdmin`
  단일 조건으로 하드코딩된 권한 체크가 남아있으면 한동안 계속 발견된다(사이드바
  진입 버튼 → 관계도 뷰어 → 멤버 다이얼로그 스코프까지 3차례 반복). 새 역할
  추가 시 관련 role-check 지점을 전수 검색하는 편이 매번 사용 중 발견하는
  것보다 나을 수 있음.

## 문제 & 해결

- **문제:** 사용자별 권한 매트릭스에서 그룹이 위임받지 않은 시스템에도 권한을
  부여할 수 있었음
  **원인:** 컬럼 목록이 전체 시스템 기준이었고 그룹 스코프 필터가 없었음
  **해결:** 그룹 선택을 필수화하고 컬럼을 `available-systems`(그룹 파생 스코프)
  API 응답으로 제한
