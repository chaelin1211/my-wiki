# 2026-05-26 (화) — 벡터 연관관계 추론 및 SQL 리버스 엔지니어링 검토

## 안건

### 1. 테이블 연관관계 추론 (FK 미설정 대응)

- 현재 테이블 추출 시 연관관계 정보가 없어 JOIN 쿼리 생성 품질 낮음
- FK가 없는 경우 LLM으로 연관관계를 추론하는 기능 실장님이 개발
  - 동작 방식: 테이블 추출 → 추출된 테이블의 직접 연관 테이블 추가 추출 (중복 제거) → 쿼리 생성 시 LLM에 함께 전달
  - 연관관계 추론 단계는 **벡터라이징 시점**에 수행
  - 연관 가능성 있는 컬럼(특정 suffix, PK 등)을 추려서 전달

### 2. 벡터라이즈 안정성

- 벡터라이즈 시 모델 재로딩 문제 → 로딩 중 API Hang 발생
- 수정 필요

### 3. SQL Reverse Engineering

- 실제 수행된 쿼리를 수집해 few-shot 예시로 활용하는 방안
- 정규화 처리 여부: 조건별 쿼리 중복 방지용 (pgsql은 기록 시 이미 처리됨)
- 수집 경로:
  - admin example 등록 화면에 명시적 수집 UI 추가
  - 백엔드에서 자동 수집되는 부분도 추가

### 4. 어드민 UI 개선

- admin example 화면 vectorize 버튼 제거
- admin에서 수정 시 즉시 반영되는 항목들 검토 후 수정
- 대화 목록 description: 마지막 메시지를 찾아와서 함께 표시하도록 수정

## 결정사항
