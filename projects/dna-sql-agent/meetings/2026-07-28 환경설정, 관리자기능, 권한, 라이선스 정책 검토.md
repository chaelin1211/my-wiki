- 복호화 모듈이 암호화된 키 파일을 읽어 정책을 반영하는 구조
- 최초 구동 시점을 저장하여 기간 기반 정책 처리
- Docker 환경 바인딩

  - hostname은 잘 변경되지 않고 MAC address는 간헐적으로 변경될 수 있어 두 값을 페어로 체크
  - 값 변경 감지 시 dat 파일 재생성
- 발급 UI
  - 별도의 발급 UI 구성 필요성 논의
  - 발급 정보는 DB에 저장하는 방향이 바람직함
