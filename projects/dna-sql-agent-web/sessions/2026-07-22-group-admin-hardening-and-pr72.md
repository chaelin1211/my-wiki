# 2026-07-22 — 그룹 관리자 화면 마무리, PR #72 머지

## 목표

백엔드([[projects/dna-sql-agent/sessions/2026-07-22-group-admin-hardening-and-pr117|dna-sql-agent 세션 로그]])
쪽 마무리 작업(default_grant 시딩, 권한 매트릭스 스코프 제한, 벌크 이동 API)에
맞춰 프론트엔드 화면을 완성하고, 그 과정에서 발견한 UI 버그들을 정리해 PR #72를
머지했다.

## 수행한 작업

1. **그룹원 관리 다이얼로그(`group-members-dialog.tsx`) 전면 재설계** — 검색어
   없을 땐 타 그룹을 접힌 카드로 보여주고 펼칠 때만 그 그룹 멤버를 페이징
   조회, 검색 시엔 그루핑 없이 그룹 뱃지 붙은 flat 무한스크롤. 우측(현재 그룹
   멤버)도 무한스크롤 전환. 신규 추가 대기는 "신규" 뱃지, 취소 시 원래 위치로
   정확히 복귀. 제거 대기는 이동 없이 muted 처리 + 원복 아이콘 (`8ae8f75`)
2. **사용자별 시스템 권한 매트릭스** — 그룹 선택 필수화 + 컬럼을 그룹 파생
   스코프로 제한(admin/기본 그룹 예외), 그룹 미선택 시 첫 그룹 자동 선택
   (`af6342c`, `fa9911b`) — 백엔드 [[projects/dna-sql-agent/decisions/026-group-admin-v0.9-refinements|ADR-026]] 반영
3. **그룹 목록/그룹 수정 다이얼로그** — 생성/삭제 시 페이지네이션 테이블이
   즉시 반영되도록 수정 (`504edc6`)
4. **사용자 목록** — 인라인 그룹 변경 시 그룹 탭도 함께 갱신, 검색 중 결과
   0건 순간 필터바가 통째로 리마운트되어 포커스가 풀리던 버그 수정 (`146cd95`)
5. **매뉴얼** — 매뉴얼 페이지에 그룹 관리자 전용 탭 추가, 관리자 매뉴얼에
   그룹 관리 탭 추가 (`505f509`, `011a6f5`)
6. **사이드바** — 그룹 관리자 전용 진입 시 버튼 라벨 "관리자" → "그룹 관리"
   (`5a557de`)
7. **시스템 목록에 그룹 배타 소유 뱃지 표시**, 시스템 다이얼로그 셀렉트 폭
   통일 (`dea164c`)
8. **버그 수정**:
   - `/relation-viewer`(테이블 관계도 뷰어)가 `isAdmin`만 확인해 그룹 관리자
     접근을 막던 문제 (`35f4d7b`)
   - SQL 예제/시스템 추가 화면에 "시스템·연결 없음" 상태 처리 누락 보완
     (`8f17b59`)
   - 새 대화 시스템 선택 다이얼로그 — 이름이 길 때 상태 아이콘이 찌그러지던
     레이아웃 버그 (`8684ac4`)
9. PR #72 생성·머지 (프론트)

## 핵심 결정

- (정책 결정은 백엔드 세션에서 이뤄짐 — [[projects/dna-sql-agent/decisions/026-group-admin-v0.9-refinements]] 참고)
- 그룹원 관리 다이얼로그를 "전체 로드 후 클라이언트 필터"에서 "접힌 카드 +
  펼칠 때만 페이징 조회"로 재설계 — 그룹 수가 늘어나도 초기 로드 비용이
  커지지 않도록 함

## 배운 것

- 새 역할(그룹 관리자) 도입 후에도 `isAdmin` 단일 체크가 남아있는 지점이
  세션마다 하나씩 발견됨(사이드바 진입 버튼 → 관계도 뷰어 → 멤버 다이얼로그
  스코프). 상세는 [[projects/dna-sql-agent/sessions/2026-07-22-group-admin-hardening-and-pr117]] "배운 것" 참고.

## 문제 & 해결

- **문제:** 사용자 목록 검색 중 결과가 잠깐 0건일 때 검색창까지 포함한
  필터바 전체가 리마운트되어 입력 포커스가 풀림
  **원인:** 결과 0건을 빈 상태(empty state)로 처리하며 필터바를 조건부
  렌더링 트리 밖에 두지 않았음
  **해결:** 필터바를 결과 유무와 무관하게 항상 렌더링하도록 구조 변경
